# GL009: Scanner disabled

| Severity | Platforms |
| --- | --- |
| HIGH | GitHub Actions, GitLab CI |

## Risk

The scanner is configured but never runs automatically, so it cannot gate anything. On GitHub Actions this is "if: false" or "if: ${{ false }}" on the step or job. On GitLab CI it is "when: never", "when: manual" (a manual job does not run unless someone starts it, and is allowed to fail by default), rules: that always resolve to never or manual, or a security template disabled with SAST_DISABLED, SECRET_DETECTION_DISABLED, DEPENDENCY_SCANNING_DISABLED, CONTAINER_SCANNING_DISABLED or DAST_DISABLED set to "true". Other rules stay quiet for disabled scanners, since the scanner does not run at all.

## Fix

Remove the condition that disables the scanner.

Before:

```yaml
include:
  - template: Jobs/Secret-Detection.gitlab-ci.yml
variables:
  SECRET_DETECTION_DISABLED: "true"
```

After:

```yaml
include:
  - template: Jobs/Secret-Detection.gitlab-ci.yml
```
