# GL010: Suppression without a reason

| Severity | Platforms |
| --- | --- |
| LOW | GitHub Actions, GitLab CI |

## Risk

A "# gatelint:ignore" comment must name the rule IDs it suppresses and give a reason of at least 10 characters, so reviewers can tell a deliberate exception from a silenced warning. A suppression without a valid reason is reported by this rule and does not suppress anything; a suppression naming an unknown rule ID is reported as well. GL010 findings cannot themselves be suppressed.

## Fix

Add a reason of at least 10 characters after the rule IDs.

Before:

```yaml
# gatelint:ignore GL004
continue-on-error: true
```

After:

```yaml
# gatelint:ignore GL004 nightly job only reports to the dashboard; the PR gate is in ci.yml
continue-on-error: true
```

See the [rule index](../../README.md#rules) for the other rules. `gatelint rules GL010` prints this description in the terminal.
